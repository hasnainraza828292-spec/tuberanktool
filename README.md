# TubeRank Tools

Free YouTube SEO helpers (tags, titles, descriptions, hashtags, keyword ideas).
Plain HTML, CSS and JavaScript. No backend, no paid API, no API key.

## Files

- index.html, tag-generator.html, title-generator.html, description-generator.html,
  keyword-tool.html, hashtag-generator.html: the home page and the five tools
- blog.html, about.html, contact.html: content pages
- privacy-policy.html, terms.html, disclaimer.html: legal pages
- style.css: all the design (white and red theme)
- script.js: all the tool logic and the mobile menu
- robots.txt, sitemap.xml: help search engines

## Test it on your computer

1. Put all files in one folder.
2. Double-click index.html. It opens in your browser and everything works.

## Before you publish (replace these placeholders)

1. YOUR-USERNAME: your GitHub username. Found in sitemap.xml and robots.txt.
2. YOUR-EMAIL@example.com: your real email. Found in contact.html and privacy-policy.html.
3. If your repository is not named tuberank-tools, change that name in sitemap.xml and robots.txt too.

## Publish on GitHub Pages (free)

1. Create a free account at github.com.
2. Click the + icon (top right), then New repository.
3. Name it tuberank-tools, choose Public, then click Create repository.
4. Click "uploading an existing file", drag in ALL the files (not the folder itself), then click Commit changes.
5. Open the repository's Settings, then Pages in the left menu.
6. Under Build and deployment, set Source to "Deploy from a branch".
7. Choose branch main and folder / (root), then click Save.
8. Wait 1 to 3 minutes and refresh. Your link will be:
   https://YOUR-USERNAME.github.io/tuberank-tools/

## Updating the site later

Open a file in your repository, click the pencil icon, edit, and click Commit changes.
The site updates in a minute or two.

## Ads

Each ad placeholder is a block with class "ad-slot". Delete it, or paste your ad code
inside the "ad-box" div once your ad account is approved. If you add ads, analytics or
cookies, update privacy-policy.html. Keep ads clearly separate from the tool buttons.

## Honest-content rule

Do not add fake search volumes, rankings or "AI" claims. The site's value is that it is
transparent about what it does.
